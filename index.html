Cloud Governance, Cost & Risk Intelligence Platform

Faculty-advised research · Python · pandas · SQL · S3 · Glue · Athena

The problem

Cloud data arrives inconsistent. The same field is present in one account and missing in the next, which breaks any analysis that assumes a fixed shape — and breaks it quietly.

What I'm building
  • Co-developing a platform that consolidates AWS resource, configuration, security and cost data across accounts and regions into one view.
  • Normalized inconsistent cloud data with Python, pandas, SQL, S3, Glue and Athena, merging every field seen across the organization into one schema so the data stays reliable for both technical analysis and business reporting.
  • Built checks for public exposure, excessive IAM permissions and unused resources, linking each finding to its security risk, operational impact and wasted cloud spend.
  • Designing a unified cost-and-risk view so stakeholders can prioritize fixes by business value and security exposure, backed by research into CIS AWS Foundations, NIST and SOC 2 controls and safe remediation with rollback and audit trails.
